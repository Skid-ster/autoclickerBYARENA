MacroClicker v1.5.1 improves tall-window scaling and fixes reliability issues in click sessions, recorded playback, settings, and updates.

## Highlights

- Tall, narrow windows reflow into a portrait layout, allowing controls to grow instead of leaving large empty gaps.
- Click-worker handoffs and configuration updates are more resilient during rapid stop and restart.

## Fixed

- Start and the toggle hotkey both apply and validate the current interval, including intervals longer than ten seconds.
- Recorded playback sends one click per recorded step, independently of the ordinary double/triple and random-offset settings.
- Failed settings saves stay pending and retry; invalid offsets no longer discard unrelated preferences.
- Update cancellation and failures better report source-checkout changes, wait for the click worker, and preserve recovery files if rollback fails.

## Compatibility

- Windows 10 21H2 or later and Windows 11, x64.
- Existing settings remain in `%APPDATA%\op-auto-clicker\settings.conf`.
- Updates remain explicit. A recognized source checkout requires Git, a clean `main` branch, and the expected GitHub origin.
- The executable is unsigned, so Windows SmartScreen may request confirmation on first launch.

## Known issue when updating from v1.5.0

If an in-app source-checkout update from v1.5.0 is interrupted or fails, the checkout may already have advanced even if the running program was not replaced. Inspect `git status` and the current commit before retrying. This release improves reporting for later update attempts.
