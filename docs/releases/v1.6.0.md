MacroClicker v1.6.0 adds a refreshed Modern interface and an at-a-glance update notification while keeping the familiar Classic style available.

## Highlights

- Choose **Classic** or **Modern**, each in **Light** or **Dark**, under **Settings → Appearance**. Previous OLED, Terminal green and Aurora themes remain available, and existing preferences are preserved.
- Modern introduces clearer section icons, rounded cards and controls, a gradient Start button, state-specific Stop styling and the bundled Outfit typeface. The dashboard's automatic resizing and reflow remain in place.
- When a newer release is confirmed, a small red **1** appears on the footer update button. It disappears when there is no available update or an installation is in progress, and returns after cancellation or failure if the update remains available.

## Fixed

- Keyboard focus can move past disabled fields and buttons in the dashboard and affected dialogs using Tab and Shift+Tab.
- Long update-version labels remain within the Updates window, with the complete value available on hover.

## Compatibility and updating

- Windows 10 21H2 or later and Windows 11, x64.
- Existing settings remain in `%APPDATA%\op-auto-clicker\settings.conf`.
- Update installation is always initiated by you. The notification does not install anything automatically. A recognized source checkout requires Git, a clean `main` branch and the expected GitHub origin.
- The executable is unsigned, so Windows SmartScreen may request confirmation on first launch.
