MacroClicker v1.5.2 improves tall-window layout and makes resizing and secondary windows more resilient.

## Highlights

- Very tall, narrow windows use more compact reflows so controls grow instead of leaving large gaps between cards and above the footer.
- Window scaling stays automatic; the manual **Window scale** percentage picker has been removed.

## Fixed

- Secondary windows fit temporarily when needed, then restore the dashboard's scale without changing the chosen window size.
- Long dialog messages can be scrolled to reach their controls. Long status messages and unusual release-version labels stay within the window; their full text is available on hover.
- The native minimum window size is refreshed when moving between displays with different DPI scaling, without requesting a resize.

## Compatibility

- Windows 10 21H2 or later and Windows 11, x64.
- Existing preferences, including saved scale values, remain in `%APPDATA%\op-auto-clicker\settings.conf`. Automatic adaptation can still be switched off in Settings.
- Update installation remains user-initiated. A recognized source checkout requires Git, a clean `main` branch, and the expected GitHub origin.
- The executable is unsigned, so Windows SmartScreen may request confirmation on first launch.

## Known issue when updating from v1.5.0

If an in-app source-checkout update from v1.5.0 is interrupted or fails, the checkout may already have advanced even if the running program was not replaced. Inspect `git status` and the current commit before retrying. v1.5.1 and later improve reporting for subsequent update attempts.
