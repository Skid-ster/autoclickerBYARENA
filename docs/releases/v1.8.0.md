MacroClicker v1.8.0 brings a more refined Modern interface while keeping the familiar Classic appearances and responsive dashboard.

## Highlights

- Modern Light and Dark feature cooler porcelain and midnight-slate surfaces, layered card headers, clearer typography and original vector details. Checkboxes and radio choices have distinct shapes and clear selected, hover, press and keyboard-focus states.
- The Start action and hotkey reminder are more legible, and an empty Modern recording shows `0.0 s` rather than negative zero. Controls keep their existing behavior and accessible labels.
- Classic Light and Dark, previous themes, automatic scaling and saved appearance preferences remain unchanged.

## Compatibility and updating

- Windows 10 21H2 or later and Windows 11, x64.
- Existing settings remain in `%APPDATA%\op-auto-clicker\settings.conf`; saved appearance choices and window-scaling preferences are retained. New installations start in Classic Light; select **Settings → Appearance → Modern**, then **Light** or **Dark**.
- Update installation is always initiated by you. A recognized source checkout requires Git, a clean `main` branch and the expected GitHub origin.
- The executable is unsigned, so Windows SmartScreen may request confirmation on first launch.
