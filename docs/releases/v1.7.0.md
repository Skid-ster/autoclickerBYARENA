MacroClicker v1.7.0 refines the Modern interface and strengthens click positioning, session reporting and settings recovery.

## Highlights

- Modern Light and Dark have refreshed surfaces, clearer card headings, original vector action icons and more distinct Start, Stop and secondary controls. Classic and the existing responsive layouts remain available.
- Fixed-position clicks and recorded playback use virtual-desktop coordinates, including negative monitor origins. A point outside connected displays stops the session with an error rather than clicking a different position.
- Fast completion, manual stop, panic and dispatch failures now produce distinct terminal status messages. Oversized, unreadable or invalid-UTF-8 settings files are preserved instead of being silently overwritten; Settings explains how to recover them, and saving remains blocked until restart.

## Compatibility and updating

- Windows 10 21H2 or later and Windows 11, x64.
- Existing settings remain in `%APPDATA%\op-auto-clicker\settings.conf`; saved appearance choices and window-scaling preferences are retained.
- Update installation is always initiated by you. A recognized source checkout requires Git, a clean `main` branch and the expected GitHub origin.
- The executable is unsigned, so Windows SmartScreen may request confirmation on first launch.
