# Bundled font

`Outfit-Regular.ttf` and `Outfit-Medium.ttf` are unmodified static Outfit
fonts used for body text and selected headings/actions in the Modern
interface. Copyright 2021 The Outfit Project Authors. They are distributed
under the SIL Open Font License 1.1 in `OFL-Outfit.txt`.

Source: [Outfit Fonts, upstream commit 9027738](https://github.com/Outfitio/Outfit-Fonts/tree/902773808eb372f70fb34e8946dd1ffe604efc79/fonts/ttf).

- Regular SHA-256: `3b64ac4f6ab6a8eebddd4b0bc03c811c43602e11e176382ab0ee6be615ab861b`
- Medium SHA-256: `dc8d9212fc57556a55d01e863071f727cd6264b748e28885d853807aeb186142`

Static fonts are bundled rather than relying on variable-font axis selection
in the UI renderer. The complete notice and license are embedded in the
executable and available offline via **Modern → Settings → Outfit license**.
Classic and the previous themes retain their original fonts.
