# Bundled font

`Outfit-Regular.ttf` is the unmodified static regular-weight Outfit font used
for the Modern interface. Copyright 2021 The Outfit Project Authors. It is
distributed under the SIL Open Font License 1.1 in `OFL-Outfit.txt`.

Source: [Outfit Fonts, upstream commit 9027738](https://github.com/Outfitio/Outfit-Fonts/tree/902773808eb372f70fb34e8946dd1ffe604efc79/fonts/ttf).
The bundled font's SHA-256 is
`3b64ac4f6ab6a8eebddd4b0bc03c811c43602e11e176382ab0ee6be615ab861b`.
The static regular font is bundled rather than relying on variable-font axis
selection in the UI renderer. The complete notice and license are embedded
in the executable and available offline via **Modern → Settings → Outfit
license**. Classic and the previous themes retain their original fonts.
